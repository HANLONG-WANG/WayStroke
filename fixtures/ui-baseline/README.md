# 阶段 A 视觉基线

`design-sha256.json` 固定原设计稿 12 个文件的 SHA-256，正式开发没有修改它们。

- `reference/`：Chromium 渲染的设计稿窗口客户区，八页、编排及九类弹窗；页面使用空配置和未接入状态，不包含窗口外评审工具。
- `native/`：正式 Tauri/WebKitGTK 应用，在独立 GNOME 50.5 Wayland 中渲染。包含八页、编排、九类弹窗及真实交互结果 `results.json`。

初始客户区均为 1280 × 857。侧栏、标题栏、主区、标题及设置容器的几何位置沿用设计稿。WebKitGTK 选择框曾比 Chromium 高 8 像素，已通过显式样式校正至 43 像素；设置行恢复为 80 像素。字体抗锯齿由渲染引擎决定。

原型假设备/窗口/执行记录与正式后台未接入、空记录、执行不可用的内容不同；这些区域保留相同布局，显示真实阶段能力。截图不代表 B–F 功能完成。九类弹窗已检查实际打开及绘制后的画面，不以点击后的同步 DOM 状态替代截图。

复验：`./scripts/build.sh` 后运行 `python3 scripts/check-ui.py`。使用临时 XDG 和私有 D-Bus；截图中创建的规则和文本不写入用户配置。`complete` 仅表示脚本所列原生配置/窗口检查通过，阶段验收仍以实施计划逐项记录为准。
