# WayStroke 声明式动作目录

本目录定义产品设计中的动作范围与参数，满足通过声明式编排进行丰富自定义的需求。HTML 设计稿提供动作选择和参数编辑；当前没有系统执行后端。目录是目标功能范围，不代表每项已完成技术验证。

## 通用行为

- 参数接受固定值或变量引用，最终界面通过值选择器插入变量，不要求用户编写代码。
- 可产生结果的动作支持命名输出变量。窗口、命令、HTTP 等结构化结果可由后续步骤读取字段。
- 步骤具备超时、失败时停止或显式继续，以及是否启用的公共设置；完整表单仍需完善。
- 输入、窗口与文件操作应明确目标。不会将权限失败、目标失效或无结果悄悄替换为其他对象。
- 动作按类别搜索，也可搜索操作名称，例如最大化、暂停或静音。
- 鼠标模拟属于执行动作，不改变辅助键不能独立触发的约定。
- 启动命令作为用户明确要求的自定义能力；D-Bus 和 HTTP 为助手补充的集成设计，均用参数表单表达。

## 结果结构与编排示例

运行命令的结果包含退出状态、标准输出和标准错误；异步启动返回进程信息，只有明确等待结束后才提供最终退出状态。HTTP 请求的结果包含状态码、响应头和正文。窗口查找返回可引用的窗口对象。文件列表返回列表。结果字段的最终命名与类型在实现规格阶段统一。

示例：读取剪贴板 → 处理文本去首尾空白 → 发送 HTTP 请求 → 按状态码进入条件分支 → 显示结果通知。所有步骤通过字段与输出变量连接。

## 技术依据与待验证项

- Mutter 提供窗口激活、最小化、最大化、全屏、移动、调整尺寸、工作区和显示器相关 API。[窗口 API](https://gnome.pages.gitlab.gnome.org/mutter/meta/class.Window.html)
- GNOME Shell 扩展可以使用 Mutter 管理窗口和工作区；实现应适配目标 Shell 版本。[扩展架构](https://gjs.guide/extensions/overview/architecture.html)
- MPRIS 定义播放、暂停、上一首、下一首与 Seek 等操作；每个播放器可能只支持其中部分能力。[播放器接口](https://specifications.freedesktop.org/mpris/latest/Player_Interface.html)
- Gio 提供 D-Bus 代理与方法调用。列出接口不代表任意服务的权限或方法已验证。[Gio DBusProxy](https://docs.gtk.org/gio/class.DBusProxy.html)

键鼠输入、剪贴板、截图、系统音量、亮度、会话操作与部分应用控制仍需 GNOME 集成验证；不靠普通网页执行这些功能。文件和网络操作涉及的路径与超时语义也需验证。

设计稿提供可复用动作管理、全宽编排、变量插入、输入与返回接口，以及 HTTP 请求头、环境变量、坐标和 D-Bus 类型化参数的编辑界面。它仅展示参数布局和示例反馈，不实现完整类型检查、递归分析、引用重命名维护或执行引擎；这些规则保留在产品规格中。D-Bus 参数类型的完整支持范围和输出字段需在实现阶段验证。
