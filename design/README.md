# WayStroke 界面设计稿

直接打开 `index.html`，或在项目根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory design
```

浏览器访问 http://127.0.0.1:8765 。窗口内为桌面应用设计；窗口外“界面评审”工具用于查看默认、空状态、错误示例、桌面状态、初次设置与执行详情，不属于正式应用。

自由绘制、编辑动作、页面切换和简单页内文本替换可操作。编辑数据保存在当前浏览器。配置导入仅显示固定摘要；导出、恢复与导入完成为示例反馈。运行和执行结果采用固定样本，不连接系统，也不对编排求值。选择空状态或错误示例不会删除编辑数据；切回默认示例继续编辑。

需求与复杂规则见 [产品规格](../docs/product-design.md)，动作参数见 [动作目录](../docs/action-catalog.md)，开发顺序见 [完整开发计划](../docs/implementation-plan.md)。规则连续滚动和动作编排三栏已获认可，其他现有页面由用户自行复查并反馈；当前设计稿作为正式客户区复刻基线，不代表产品功能已经实现。

2026-10-13：已补齐技术验证后的界面差异：窗口最小化/最大化/关闭、未保存关闭确认、关闭设置与退出程序的区别、鼠标选择/管理员授权、文本适配范围、终端普通及密码替换开关、锁屏取消与动作排队/停止。运行状态不再将组件连接等同于全部应用可用，鼠标授权与文本接入分别显示；诊断摘要与选定场景一致。

窗口控制在浏览器中只作用于预览窗口；关闭或最小化后可在窗口外“更多示例”中重新打开。输入场景与动作执行状态采用固定评审样本，没有完整执行器或实时模拟。恢复示例数据已移到窗口外，不进入正式设置页面。

已检查八个页面、适配/授权/锁屏状态、窗口控制、未保存的编排关闭、执行详情与停止。正式壳层仍需核对实际拖动、缩放、关闭和 WebKitGTK 渲染，并将示例数据替换为后台结果；这些是实现验证，不是重新设计页面。

正式开发约束：窗口客户区一比一复刻，全部页面、弹窗、状态和操作绑定真实功能。开发计划已逐页列出依赖与验收；设计稿的固定样本、浏览器存储和示例反馈不得作为正式软件的完成实现。

2026-10-16：正式客户端的应用范围交互已按用户批准调整：共享应用选择器支持已安装应用搜索、窗口选取及手动填写，以应用 ID 保存；手势应用范围合并到窗口匹配，标题条件显式选择。设计稿中的固定应用下拉仍是旧版示例，相关正式交互以产品规格和 `apps/desktop/src/applications.js` 为准，不再要求复刻旧选单。
